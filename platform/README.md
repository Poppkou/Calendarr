# Пульс Тур — расписание тура с уведомлениями

Турфирма ведёт расписание тура в веб-офисе: вылеты, трансферы, экскурсии.
Турист открывает личную ссылку (или QR-код с памятки), видит **своё** расписание
и получает напоминания заранее — в браузере/на телефоне и в Telegram. Если офис
меняет время, туристы сразу получают уведомление «⚠️ Изменение».

```
 Офис турфирмы (/admin/)  ──►  Cloudflare Worker + D1 (база)  ──►  планировщик раз в минуту
                                      │                                    │
                                      ▼                                    ▼
          Турист (/t/<личная ссылка>/) ◄──────── Web Push · Telegram · календарь телефона (.ics)
          расписание хранится офлайн
```

## Что внутри

| Путь | Что это |
|---|---|
| `src/index.ts` | Точка входа: маршруты, раздача приложения, cron-обработчик |
| `src/dispatch.ts` | Диспетчер уведомлений — сердце надёжности (см. ниже) |
| `src/schedule.ts` | Расчёт напоминаний, тихие часы, тексты уведомлений |
| `src/time.ts` | Часовые пояса (перевод «местное время события» → UTC, летнее время) |
| `src/push.ts` | Web Push без зависимостей: VAPID + шифрование aes128gcm |
| `src/telegram.ts`, `src/routes/telegram.ts` | Telegram-бот: `/start`, `/next`, `/today`, `/stop` |
| `src/routes/admin.ts` | API офиса: вход, группы, события, туристы, рассылки, журнал |
| `src/routes/tourist.ts` | API туриста: расписание, подписка на push, экспорт `.ics` |
| `migrations/` | Схема базы D1 |
| `public/app/` | Приложение туриста (PWA) |
| `public/admin/` | Офис турфирмы |
| `public/sw.js` | Service worker: офлайн, показ уведомлений, восстановление подписки |
| `test/` | 32 теста: часовые пояса, шифрование push, расписание, полный сценарий API |

## Как обеспечена стабильность

- **Расписание считает сервер, а не телефон.** Напоминания приходят, даже если турист ни разу
  не открывал приложение после подписки.
- **Часовые пояса.** У каждого события хранится время «как в программе» плюс пояс места
  (вылет из Москвы — по Москве, экскурсия — по Стамбулу) и точный момент в UTC. Смена пояса
  на телефоне туриста ничего не ломает. Переходы на летнее время покрыты тестами.
- **Уведомление не теряется и не дублируется.**
  - Отправка в каждый канал — отдельная запись с `UNIQUE (уведомление, канал)`.
  - Перед отправкой запись «захватывается» на 5 минут. Если запуск упал на середине,
    следующий запуск отправит сообщение сам.
  - Два параллельных запуска не отправят одно сообщение дважды.
- **Повторы при сбоях.** Сеть, 429 или 5xx — повтор через 30 с, 2, 5 и 15 мин. Мёртвые подписки
  (404/410, бот заблокирован) отключаются автоматически.
- **Нет «напоминаний задним числом».** После долгого простоя устаревшее «за 2 часа» не уйдёт,
  но актуальное «за 30 минут» уйдёт.
- **Тихие часы.** Заблаговременные напоминания, которые выпали бы на 23:00–07:00, переносятся
  на 21:00 накануне — раньше, а не позже.
- **Изменения.** Правка времени или места пересчитывает напоминания и (по галочке) сразу шлёт
  туристам «Изменение» с новым и старым временем. Одновременное редактирование двумя
  менеджерами не перетирает правки: при конфликте сервер отвечает ошибкой 409.
- **Несколько каналов.** Web Push, Telegram-бот и экспорт в календарь телефона. Будильники
  календаря срабатывают даже без интернета за границей.
- **Офлайн.** Расписание сохраняется на телефоне. Без сети турист видит последнюю версию с пометкой
  «нет интернета». Неверные часы на телефоне поправляются по времени сервера.
- **iPhone.** Ссылка с личным токеном в адресе: иконка на экране «Домой» открывает именно
  этот тур. Туристу показывается понятная инструкция, как включить уведомления.
- **Наблюдаемость.** `GET /api/health` отдаёт 503, если планировщик не запускался больше 3 минут.
  Офис показывает индикатор «Уведомления работают» и журнал доставки по каждому сообщению.
- **Изоляция и безопасность.**
  - Каждая турфирма видит только свои данные (проверено тестами).
  - Пароли хешируются PBKDF2, вход ограничен 10 попытками за 15 минут.
  - Ссылку туриста можно отключить или перевыпустить.
  - Webhook Telegram защищён секретом.

## Запуск локально

```bash
cd platform
npm install
npm run vapid               # сгенерировать ключи, вписать в .dev.vars (см. ниже)
npm run db:migrate:local
npm run dev                 # http://localhost:8787
```

Файл `.dev.vars` (не коммитится):

```
VAPID_PUBLIC_KEY=...
VAPID_PRIVATE_KEY=...
VAPID_SUBJECT=mailto:you@example.com
SETUP_KEY=любая-длинная-строка-от-16-символов
```

- Офис: http://localhost:8787/admin/ → «Создать агентство» (нужен `SETUP_KEY`).
- Проверить планировщик вручную: `curl "http://localhost:8787/__scheduled?cron=*+*+*+*+*"`.
- Тесты: `npm run check` (typecheck + 32 теста).

## Деплой в Cloudflare (один раз, ~20 минут)

Бесплатного тарифа Workers хватает для старта: cron, D1 и до 40 отправок за минутный запуск.
На платном тарифе ($5/мес) поднимите `MAX_SENDS_PER_RUN` до 400.

1. Войдите в Cloudflare: `npx wrangler login`.
2. Создайте базу: `npx wrangler d1 create pulse-tour` и вставьте `database_id` в `wrangler.toml`.
3. Сгенерируйте ключи и задайте секреты:
   ```bash
   npm run vapid
   npx wrangler secret put VAPID_PUBLIC_KEY
   npx wrangler secret put VAPID_PRIVATE_KEY
   npx wrangler secret put SETUP_KEY
   ```
   ⚠️ VAPID-ключи генерируются **один раз**. Если их поменять, всем туристам придётся заново
   включать уведомления.
4. В `wrangler.toml` укажите `VAPID_SUBJECT` (ваш e-mail) и `PUBLIC_URL` (адрес сайта).
5. Деплой: `npm run deploy`. Команда прогонит тесты, применит миграции и выложит воркер.
6. Откройте `https://<ваш-адрес>/admin/` → «Создать агентство».
7. **Telegram-бот (очень рекомендуется):**
   1. Создайте бота у [@BotFather](https://t.me/BotFather).
   2. Задайте секреты `TELEGRAM_BOT_TOKEN` и `TELEGRAM_WEBHOOK_SECRET`
      (случайная строка из латиницы и цифр).
   3. Укажите `TELEGRAM_BOT_USERNAME` в `wrangler.toml` и задеплойте.
   4. В офисе: «Настройки → Переподключить webhook бота».
8. **Мониторинг:** добавьте `https://<ваш-адрес>/api/health` в бесплатный UptimeRobot или
   Better Stack. Если планировщик встанет, вы узнаете об этом раньше туристов.
9. Свой домен: Cloudflare → Workers → pulse-tour → Settings → Domains.

**Без терминала, из браузера:** см. пошаговую инструкцию [`docs/DEPLOY-GUIDE.md`](../docs/DEPLOY-GUIDE.md) — деплой одной кнопкой в GitHub Actions (база, ключи и Telegram настраиваются автоматически).

## Как этим пользуется турфирма

1. **Группы → Новая группа:** название, даты, пояс места отдыха, гид, памятка.
2. **Расписание → + Событие:** тип, местное время, место сбора. Напоминания подставляются
   по типу события: вылет — за сутки, 5 и 3 часа; трансфер — за 12 ч, 1 ч и 15 мин.
3. **Туристы:** вставить список имён → у каждого появляется личная ссылка, QR-код и код вида
   `ABCD-1234`. Отправить через WhatsApp или Telegram, либо распечатать памятки с QR.
4. Индикатор «с уведомлениями N из M» показывает, кому стоит позвонить и помочь подключиться.
5. **Сообщение группе:** срочные новости («Автобус задерживается на 15 минут»).
6. **Копировать на новые даты:** следующий заезд по той же программе — в один клик.

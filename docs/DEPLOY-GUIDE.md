# Как запустить «Пульс Тур» в интернете — инструкция для новичка

Ничего устанавливать на компьютер не нужно: всё делается в браузере. Займёт 30–40 минут.

---

## Часть 1. Что мы сейчас делаем и зачем

Сейчас программа существует только в виде файлов в вашем репозитории на GitHub. Это как
чертёж дома: всё нарисовано, но жить там пока нельзя. Чтобы турфирмы и туристы могли
пользоваться системой, её нужно **разместить на сервере** — компьютере, который работает
круглосуточно и доступен из интернета. Этот процесс называется **деплой**.

Участвуют три сервиса:

| Сервис | Простыми словами | Цена |
|---|---|---|
| **GitHub** | «Склад» с файлами программы. Там же есть «робот» (GitHub Actions), который по кнопке берёт файлы и отправляет их на сервер | Бесплатно |
| **Cloudflare** | «Сервер в аренду». Там работает программа и хранится база данных (группы, события, туристы). Раз в минуту он проверяет, кому пора отправить напоминание | Бесплатно для старта |
| **Telegram** | Бот, который присылает туристам напоминания в Telegram | Бесплатно |

Ваша задача — **один раз** связать эти три сервиса. Для этого нужно:

1. Получить в Cloudflare два «пропуска»: ID аккаунта и токен. С ними робот GitHub сможет
   выкладывать программу в ваш аккаунт.
2. Положить эти пропуска в «сейф» GitHub (раздел Secrets).
3. Нажать кнопку «Run workflow».

Всё остальное робот сделает сам:
- создаст базу данных;
- сгенерирует ключи для уведомлений;
- выложит программу;
- подключит Telegram-бота;
- проверит, что всё работает.

---

## Часть 2. Как будет работать система

**Для турфирмы.** Менеджер открывает в браузере адрес вида
`https://pulse-tour.ВАШ-АДРЕС.workers.dev/admin/` и входит по e-mail и паролю. Дальше:

1. Создаёт группу: «Стамбул, 12–17 мая».
2. Добавляет события: вылет, трансфер, экскурсии — с временем, как в программе тура.
3. Вставляет список туристов. Каждый получает **личную ссылку**, **QR-код** и **код** вида `ABCD-1234`.
4. Отправляет ссылки в WhatsApp или Telegram, либо печатает памятки с QR-кодами.
5. Если что-то поменялось, правит время. Туристы **сразу** получают «⚠️ Изменение: трансфер перенесён на 07:30».
6. Может отправить группе срочное сообщение: «Автобус задерживается на 15 минут».

**Для туриста.** Ничего не скачивает и не регистрируется. Открывает ссылку или наводит камеру на
QR-код и видит своё расписание:
- обратный отсчёт до ближайшего события;
- программу по дням;
- кнопку «Связь» для звонка гиду.

Дальше он нажимает «Включить напоминания» или «Получать в Telegram». Напоминания приходят
заранее: например, о трансфере — накануне вечером, за час и за 15 минут. Расписание сохраняется
в телефоне и открывается даже без интернета.

**Что происходит «под капотом».** Сервер Cloudflare раз в минуту проверяет, кому пора что-то
отправить, и отправляет. Телефон туриста для этого включать не нужно: напоминание придёт, как
обычное сообщение.

## Часть 3. Пошаговая инструкция

### Шаг 1. Перенести новые файлы в основную ветку GitHub (2 минуты)

Все новые файлы сейчас лежат в отдельной «ветке» — черновой копии репозитория. Кнопка
деплоя появится только после того, как черновик перенесут в основную ветку. Это называется
«слить» (merge).

1. Попросите меня в чате: **«создай pull request»**. Я пришлю ссылку.
   Либо сделайте сами: откройте https://github.com/poppkou/calendarr — сверху появится жёлтая
   плашка с кнопкой **«Compare & pull request»**. Нажмите её, затем зелёную кнопку
   **«Create pull request»**.
2. На странице запроса прокрутите вниз и нажмите зелёную кнопку **«Merge pull request»**,
   затем **«Confirm merge»**.

✅ Готово, если на странице появилась фиолетовая надпись **«Merged»**.

> Ваш личный календарь при этом не изменится: новые файлы лежат в отдельных папках.

### Шаг 2. Зарегистрироваться в Cloudflare (5 минут)

1. Откройте https://dash.cloudflare.com/sign-up
2. Введите e-mail и придумайте пароль. Подтвердите почту по ссылке из письма.
3. Если Cloudflare спросит, что вы хотите сделать, или предложит добавить сайт (домен),
   пропустите этот шаг. Домен не нужен.
4. В меню слева найдите **«Compute (Workers)»** → **«Workers & Pages»** (название раздела может
   немного отличаться). Откройте его один раз.
   - Если Cloudflare предложит **выбрать поддомен** (subdomain) для `workers.dev`, придумайте
     короткое слово латиницей, например `suntour`. Из него получится адрес вашего сайта:
     `https://pulse-tour.suntour.workers.dev`.
   - Создавать в этом разделе ничего не нужно.

### Шаг 3. Найти Account ID (1 минута)

Account ID — номер вашего аккаунта в Cloudflare. Это не секрет, но он понадобится роботу.

1. Откройте главную страницу Cloudflare: https://dash.cloudflare.com
2. Справа на странице «Workers & Pages» или в разделе **«Account home»** найдите строчку
   **«Account ID»**. Это 32 символа из цифр и латинских букв, например `a1b2c3d4e5…`.
   - Если не видите её, нажмите на три точки ⋯ рядом с названием аккаунта и выберите
     **«Copy account ID»**.
3. Скопируйте ID и сохраните в «Заметки» на время настройки.

### Шаг 4. Создать API-токен (5 минут)

Токен — это «пропуск» для робота GitHub: он разрешает выкладывать программу в ваш аккаунт.

1. Откройте https://dash.cloudflare.com/profile/api-tokens
2. Нажмите синюю кнопку **«Create Token»**.
3. Найдите шаблон **«Edit Cloudflare Workers»** и нажмите **«Use template»** справа от него.
4. В разделе **Permissions** нажмите **«+ Add more»** и добавьте строку:
   **Account** → **D1** → **Edit**. Это разрешение на работу с базой данных.
5. В разделе **Account Resources** выберите: **Include** → **ваш аккаунт**.
6. В разделе **Zone Resources** выберите: **Include** → **All zones**.
7. Внизу нажмите **«Continue to summary»**, затем **«Create Token»**.
8. Появится длинная строка — это и есть токен. **Скопируйте его сразу**: второй раз его не
   покажут. Сохраните в «Заметки».

> ⚠️ Никому не пересылайте токен, в том числе не вставляйте его в этот чат. Он нужен только
> в сейфе GitHub (следующий шаг). Если токен случайно попал не туда, удалите его на той же
> странице и создайте новый.

### Шаг 5. Придумать пароль настройки SETUP_KEY (1 минута)

Этот пароль понадобится один раз — чтобы создать в системе вашу первую турфирму. Ещё он
защищает от того, чтобы кто-то посторонний создал агентство на вашем сайте.

Придумайте пароль **не короче 16 символов**, например `Solnce-Tour-2026-Start!`.
Запишите его в надёжное место.

### Шаг 6. Создать Telegram-бота (5 минут, очень рекомендуется)

1. В Telegram найдите **@BotFather** — официальный бот для создания ботов, с синей галочкой.
2. Нажмите **«Start»** и отправьте команду `/newbot`.
3. Введите имя бота, которое увидят туристы, например `Солнце Тур — напоминания`.
4. Введите короткое имя латиницей, оканчивающееся на `bot`, например `SunTourRemindBot`.
5. BotFather пришлёт сообщение со строкой вида `7712345678:AAH...` — это **токен бота**.
   Скопируйте его.

### Шаг 7. Положить «пропуска» в сейф GitHub (5 минут)

1. Откройте https://github.com/poppkou/calendarr/settings/secrets/actions
   (вкладка **Settings** → слева **Secrets and variables** → **Actions**).
2. Нажмите зелёную кнопку **«New repository secret»**. В поле **Name** впишите имя ровно как
   в таблице ниже (заглавными буквами), в поле **Secret** вставьте значение. Нажмите
   **«Add secret»**.
3. Повторите для каждой строки:

| Name (имя — точно так) | Secret (значение) |
|---|---|
| `CLOUDFLARE_API_TOKEN` | токен из шага 4 |
| `CLOUDFLARE_ACCOUNT_ID` | Account ID из шага 3 |
| `SETUP_KEY` | пароль из шага 5 |
| `TELEGRAM_BOT_TOKEN` | токен бота из шага 6 (если создали) |

✅ Готово, если в списке **Repository secrets** видны 3–4 строчки. Значения GitHub больше
не показывает — так и должно быть.

### Шаг 8. Нажать кнопку деплоя (5 минут ожидания)

1. Откройте https://github.com/poppkou/calendarr/actions
   - Если GitHub спросит, включить ли Actions, нажмите **«I understand my workflows, go ahead
     and enable them»**.
2. Слева выберите **«Пульс Тур»**.
3. Справа нажмите **«Run workflow»**. В выпадающем окне:
   - Branch: **main** (или **master**);
   - поставьте галочку **«Задеплоить в Cloudflare после проверок»**;
   - нажмите зелёную кнопку **«Run workflow»**.
4. Через несколько секунд появится строка с жёлтым кружком — робот работает. Он проходит два
   этапа:
   - **check** — проверяет программу (32 автотеста);
   - **deploy** — выкладывает её в Cloudflare.
5. Когда кружок станет **зелёной галочкой ✅**, нажмите на эту строку. Внизу страницы появится
   табличка **«✅ Пульс Тур задеплоен»** с адресами:
   - **Офис турфирмы** — `https://pulse-tour.ВАШ-АДРЕС.workers.dev/admin/`
   - **Вход для туристов** — `.../app/`
   - **Telegram-бот** — ссылка на бота

Если вместо галочки **красный крестик ❌** — нажмите на строку, затем на этап **deploy**.
Робот пишет причину по-русски, например «Не задан секрет SETUP_KEY». Исправьте и нажмите
**«Re-run all jobs»**. Если непонятно — пришлите мне скриншот или текст ошибки.

### Шаг 9. Создать турфирму и проверить на себе (10 минут)

1. Откройте адрес **«Офис турфирмы»** из шага 8.
2. Внизу нажмите **«Создать агентство»** и заполните форму:
   - **ключ настройки** — пароль SETUP_KEY из шага 5;
   - название турфирмы;
   - ваш e-mail;
   - пароль для входа.
3. Нажмите **«+ Новая группа»**: например «Тест», даты — сегодня и завтра, пояс — «Москва».
4. Добавьте событие **на 20–30 минут вперёд** от текущего времени. В «Напомнить за» отметьте
   **10 мин** и **в момент**.
5. Откройте вкладку **«Туристы»**, впишите своё имя и нажмите **«Добавить по именам»**.
6. Нажмите **«Ссылка / QR»** и отсканируйте QR-код камерой своего телефона.
7. На телефоне нажмите **«Включить напоминания»** и/или **«Получать в Telegram»**. Должно прийти
   проверочное уведомление.
   - **iPhone:** сначала нажмите в Safari «Поделиться» ⬆️ → **«На экран „Домой“»**, откройте
     появившуюся иконку и уже там нажмите «Включить напоминания». Либо просто подключите Telegram.
8. Дождитесь времени события — за 10 минут и в момент начала должны прийти напоминания.
9. В офисе поменяйте время события — на телефон придёт «⚠️ Изменение».

✅ Если всё пришло — система полностью работает.

### Шаг 10. Мониторинг: узнать о сбое раньше туристов (5 минут, рекомендуется)

1. Зарегистрируйтесь на https://uptimerobot.com (бесплатно).
2. Нажмите **«Add New Monitor»** → тип **HTTP(s)** → адрес
   `https://pulse-tour.ВАШ-АДРЕС.workers.dev/api/health` → интервал 5 минут.
3. Если отправка уведомлений остановится, вам придёт письмо.

## Частые вопросы

**Сколько это стоит?**
На старте — 0 ₽. Бесплатного тарифа Cloudflare хватает на десятки групп. Если турфирм станет
много, тариф Workers Paid стоит $5 в месяц.

**Как обновлять программу, когда я (или я с Claude) что-то поменяю?**
Изменения сливаются в основную ветку, затем снова: Actions → «Пульс Тур» → Run workflow →
галочка. Данные (группы, туристы) и подписки туристов при обновлении сохраняются.

**Можно ли свой адрес, например `tour.solnce.ru`?**
Да. Это делается позже: в Cloudflare → Workers & Pages → pulse-tour → Settings → Domains.
Затем в GitHub → Settings → Secrets and variables → Actions → вкладка **Variables** добавьте
`PUBLIC_URL` = `https://tour.solnce.ru` и запустите деплой ещё раз.

**Что если я потеряю пароль от офиса?**
Другой сотрудник-владелец может создать вам новый вход. Если владелец один — напишите мне,
восстановим через базу данных.
